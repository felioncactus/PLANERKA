# PLANЁRKA

PLANЁRKA is a full-stack student planning workspace developed as a university capstone project. The application helps students manage courses, tasks, planned study blocks, activities, notes, friends, chats, and productivity statistics from one web interface.

The repository contains a React/Vite frontend and a Node.js/Express API backed by PostgreSQL. Optional OpenAI-powered features are included for task planning, study assistance, note help, and statistics insights when an API key is configured.
